Конфликт слияния возникает при попытке объединить две ветки, когда система контроля версий не способна самостоятельно выбрать правильную версию кода. Причиной стало одновременное и независимое изменение одного и того же участка файла в разных ветках. Чтобы устранить проблему, я открыла проблемный файл, убрала разделительные метки Git и привела код к нужному виду. После правки я сохранила изменения в индекс (git add) и завершила процесс объединения веток новым коммитом (git commit)
